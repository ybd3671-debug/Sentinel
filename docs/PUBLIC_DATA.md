# 真实公开报价与数据边界

在没有扶摇/iFinD访问凭据时，本版本增加腾讯公开报价作为独立可选模式。五个内置标的已实际取回响应并通过价格/前收盘/涨跌幅一致性校验；这项取数验证在本机完成，云端连通性另行验收，不据此宣称云端已验证。

来源固定为 `https://qt.gtimg.cn/q=<代码>`，代码来自服务端白名单：沪深300 sh000300、上证指数 sh000001、创业板指 sz399006、贵州茅台 sh600519、宁德时代 sz300750。服务端不接受任意上游地址。

公开报价不是带有可用性承诺的正式数据服务，可能延迟、变更格式或拒绝访问。适配器当前只提供价格、前收盘、涨跌幅及报价时点，不臆造事件、热度和量比。混合这些字段的任务需要演示模式或完整自定义行情接口，公开模式会明确拒绝创建。

## 可追溯字段

响应是GB18030文本。单条记录以波浪号分隔；当前响应中证券代码位于2、价格3、前收盘4、上海报价时点30、供应商返回涨跌幅32（从0计数）。这是基于直接响应验证的适配映射，不宣称是官方稳定SDK契约。

运行记录保留响应原文、字段位置、供应商来源、原始报价时间及取回时间。使用供应商返回的百分数执行阈值比较；同时用价格/前收盘复算，偏差超过0.02个百分点标记为冲突。响应代码、字段数量、日期、价格或格式不符合预期时停止解析。

新取回的旧报价仍然是旧数据。价格判断要求原始报价不超过3分钟；不以服务器取回时间替代报价时间。过期会解释为“可能休市或来源延迟”，暂停价格判断，不虚构正常结果。单纯日期提醒只使用上海系统日历，不依赖金融报价。

价格轮询可能错过两次检查之间出现又解除的条件；当前云端最小间隔为60分钟，不提供实时或逐笔告警承诺。演示模式继续使用明确标注的构造数据，适合验证触发、冷却、去重和故障恢复。

扶摇官方文档已成功读取，其页面提供API Key管理及统一ApiResponse说明；当前没有用户凭据，尚未接入扶摇或iFinD，不能把腾讯公开报价写成题目指定供应商已接入。
