1. 新建监控，输入“沪深300当日跌幅超过2%，冷却60分钟”，生成草稿。
2. 核对负数阈值、严格小于关系、检查间隔和冷却。云端最小检查间隔为60分钟，草稿会明确提示调整；手动检查随时可用。
3. 确认演示模式并创建任务，点击立即检查，查看未满足原因与字段证据。
4. 在场景验证台选择条件满足，查看原始快照、时点、来源、单位、版本和比较结果。
5. 连续选择条件满足，验证冷却和提醒去重。选择数据过期、缺失、冲突、接口失败，验证待核验。选择条件解除，检查恢复记录。
