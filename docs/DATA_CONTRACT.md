# 行情数据契约

GET MARKET_API_URL?symbol=000300.SH。若配置 MARKET_API_KEY，服务端发送 Bearer 认证。地址仅由服务端环境变量设定，访问者不能提交任意上游URL。

```json
{
  "symbol": "000300.SH",
  "price": 3892.4,
  "changePct": -0.82,
  "volumeRatio": 1.12,
  "heat": 43,
  "event": "原始公告或资讯文本",
  "asOf": "2026-10-19T06:00:00.000Z",
  "source": "供应商 / 接口名称 / 原始记录ID",
  "conflict": false
}
```

以上值仅为格式示例，不是真实行情。涨跌幅以百分数表示，-2代表-2%，不是-0.02；价格为元或指数点，标的类型应由数据适配层确定。量比、热度必须记录供应商统计口径，不能跨供应商直接比较。

时间必须含时区，记录的是行情快照时点，不是代理取回时点。快照超过3分钟或比服务器时间超前1分钟则拒绝判断。标的不匹配、冲突标志或规则必要字段缺失也拒绝判断。字段不能用字符串伪装为数字。

扶摇/iFinD返回格式必须通过适配器转换后再使用；本项目没有臆造供应商私有端点。当前单来源接口的 conflict 标志由适配层提供，并未实现多源对账。

事件正文应保留原文链接/ID到source中。当前只匹配返回的文本，不负责去重资讯或评估事件重要性。日历来自服务器上海日期；没有交易日历接入。
