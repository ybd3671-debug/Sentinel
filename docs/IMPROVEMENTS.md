# 本轮改进记录

## 规则正确性

- 混合且/或、括号分组会要求澄清，不再直接展平成任一满足。
- 今天、明天、后天按上海时区固定为具体日期，并在草稿中解释；不支持的相对时间和时刻拒绝生成。
- 同一字段的多个条件及省略字段的区间上下界全部保留；矛盾上下界或日期拒绝创建。
- 不能理解的剩余文字明确报错，不再忽略未知限制。带引号的事件关键词独立解析。
- 模型提示词统一严格/包含等号的语义；对于本地可明确解析的输入，模型草稿还需与确定性规则一致，否则拒绝。
- 规则字段和运算符使用自有属性白名单，避免继承属性混入规则。

## 数据与解释

- 新增可选腾讯公开报价，支持真实价格与涨跌幅；不需要用户提交密钥。
- 报价时点、取回时点和检查时点分开记录，保留供应商原文及字段位置。
- 日历任务不再因金融行情不可用而被阻塞。
- 调度记录保存完整规则快照、版本和手动/自动来源，提交失败计入失败数，不伪装成正常零检查。

## 产品体验与验收

- 新增手动配置入口，展示下次到期时间、冷却倒计时和检查来源。
- 场景按钮改为实际下跌/回升数值，不承诺必然满足任意用户规则。
- 增加GitHub Actions自动测试与构建；发布后可独立运行公开站点主链路和真实行情取回验收。
- 当前本地41项自动检查全部通过。真实部署、GitHub云端验收和首次定时执行的结果需另附实际证据，不能从“写好了工作流”推断运行成功。
