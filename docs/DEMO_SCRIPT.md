# 90–120秒演示脚本

说明：这是录制脚本，尚不是视频文件。建议使用浏览器窗口录屏，不讲PPT。

0–15秒：打开监控总览。“哨点帮助研究者把关注点转成明确规则，重点是解释为什么触发，以及为什么不能判断。当前演示使用构造数据，不冒充实时行情。”

15–40秒：新建监控，输入“沪深300当日跌幅超过2%，冷却60分钟”。生成草稿，指出阈值为-2、组合关系、检查间隔、冷却和数据模式。点击确认。

40–65秒：立即检查，展示未满足结果。选择条件满足，展示实际-3.12对比阈值-2、快照来源、时点及版本。关闭证据，再次选择条件满足，展示冷却，提醒中心只产生一次提醒。

65–90秒：选择数据过期或接口失败，显示待核验，强调不会把失败当成正常。选择条件解除，展示恢复记录。编辑阈值生成v2，保留v1运行记录。

90–120秒：展示运行记录和导出。最后打开数据与说明，诚实说明当前本地解析、构造数据、真实接入及云端调度的实际状态。“模型负责草稿，规则负责判断，证据负责解释。”
