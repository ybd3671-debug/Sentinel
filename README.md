# 哨点 Sentinel · 可配置投资监控与风险雷达

面向需要持续关注少量标的的个人研究者，把自然语言关注点转成可检查、可编辑的规则，并解释为什么提醒、为什么未提醒、为什么暂时不能判断。

## 启动

需要 Node.js 22.13+（建议24）。无需第三方依赖，也无需密钥即可运行演示模式。

```sh
node server.mjs
```

打开 http://127.0.0.1:8787 。SQLite 数据保存在 `data/sentinel.sqlite`，重启保留。服务进程每30秒检查到期任务；任务间隔可设1至1440分钟，离线期间不执行，重启后补一次到期检查，不伪造错过的历史行情。服务器绑定本机回环地址。

可选配置：复制 `.env.example` 为 `.env`，填写后执行 `node --env-file=.env server.mjs`。不需要使用 npm 安装依赖。

## 体验路径

1. 新建监控，输入“沪深300当日跌幅超过2%，每小时检查，冷却60分钟”。
2. 生成规则草稿；检查标的、负数阈值、AND/OR、检查间隔和冷却。
3. 确认规则，选择演示模式，创建任务。
4. “立即检查”得到未满足条件的结果，展开字段证据和原始快照。
5. 场景验证台选择条件满足、重复满足、数据过期、缺失、冲突、接口失败、条件解除；观察提醒、冷却、待核验和恢复。
6. 编辑生成新版本，暂停/恢复任务，在运行记录和提醒中心核验结果，导出 JSON 审计文件。

## 产品设计

自然语言仅产生草稿，确认是监控生效的边界。统一任务模型包含标的、条件数组、组合关系、检查间隔、冷却、版本和运行状态。每次检查保存规则版本、原始快照、来源、时点、单位及逐条件比较结果。

价格、涨跌幅、量比、热度、日历、事件关键词共用条件模型。当前没有组合持仓分析或复杂事件语义识别。日期是上海自然日，尚未接入交易日历。

状态：监控中、暂停、冷却、待核验。首次满足触发产品内提醒；冷却期内重复满足不提醒，冷却后持续满足同样去重，直到条件解除并再次满足。编辑生成新版本并重新布防。过期超过3分钟、来源冲突、必要字段缺失、未来时间及接口失败均不生成正常判断；保留任务，下次检查自动重试。

## AI角色与实际状态

当前无需密钥的版本使用明确标注的有限语法本地解析器，**不宣称调用了大模型**。配置 OpenAI-compatible 接口的 `AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL` 后，由服务端模型将自然语言转换为同一结构，输出仍经过校验和用户确认。此路径已有实现，因无密钥尚未做真实模型联调。模型不参与规则执行或编造市场解释。

## 数据与真实接口

演示行情全部为构造数据，不是市场事实。每条记录显式标注模式，不能用于投资判断。扶摇/iFinD 优先方案尚缺访问权限，未完成具体供应商接口适配。真实接口通过服务端 `MARKET_API_URL` / `MARKET_API_KEY` 配置，返回格式见 `docs/DATA_CONTRACT.md`。没有凭据时不会开放真实模式创建。

## 检查和打包

```sh
node --test tests/engine.test.mjs tests/service.test.mjs tests/public.test.mjs
node scripts/build.mjs
node scripts/validate-artifact.mjs
```

前端源码：`public/`；确定性规则引擎：`src/engine.mjs`；接口/调度：`src/service.mjs`；SQLite/D1存储适配：`src/store.mjs`。构建会把界面与服务模块嵌入 Worker ESM，输出 `dist/server/index.js`。本机版本自动调度；Worker导出scheduled handler，并通过托管云任务每小时唤醒受保护接口；实际心跳超过2小时未更新会提示异常。外部调度可 POST `/api/tick` 并带 `Authorization: Bearer <SCHEDULER_TOKEN>`；未配置或认证失败返回401。

## 安全与未做事项

- 密钥只在服务端环境变量，`.env`、数据库和部署包不进入源仓库。
- 公开演示采用匿名浏览器工作区，随机256位HttpOnly Cookie隔离任务与记录。不同访客无法读取或修改彼此任务；不收集真实身份。Cookie保留30天，清除后无法找回原工作区。未实现账号登录及跨设备恢复。
- 没有短信/邮件/微信；提醒保存在产品提醒中心。
- 云端调度使用托管云任务每小时唤醒，实际执行状态以页面心跳为准。真实行情和真实大模型未接入。演示模式是可操作的规则系统，不能代替真实集成验收。
- 支持五个内置标的，不提供任意股票搜索。热度、量比需供应商定义；事件是关键词匹配。无交易日过滤、回测、资金流或交易执行。
- 全站最近500次运行日志保留，各工作区仅能看到自身记录；版本历史附于任务。大型长期审计需独立归档。
- 运行状态和日志使用SQLite事务或D1批次一起提交，并通过原始任务内容进行乐观并发校验；同一进程内的检查按任务串行执行。发生跨实例竞争时保留已提交结果并返回重试提示。
- 不输出确定性涨跌预测、收益承诺、直接买卖或仓位建议。
